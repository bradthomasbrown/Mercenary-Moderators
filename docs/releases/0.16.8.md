# Mercenary Moderators 0.16.8 · user extension

This is the first GitHub release of the existing user extension. It contains the same installer already offered on [the MM website](https://mm.bradthomasbrown.com/), with no extension behavior changes for this GitHub release.

## Download

Choose **mm-user-0.16.8.zip** under Assets. This is the installable Orion extension. GitHub's automatically generated **Source code** archives contain the repository and are not the installer.

The installer contains local tagging and filtering, market browsing and listing, FREE balances, subscriptions, local error traces, and optional encrypted identity backups. Developer execution features are excluded.

## Install in Orion on iPhone

1. Save `mm-user-0.16.8.zip` in Files.
2. In Orion, open Extensions → + → Install from File and select the ZIP.
3. Enable the extension, allow it on `boards.4chan.org`, and open or reload a thread.

[Installation help and usage wiki](https://mm.bradthomasbrown.com/wiki#install) · [Identity and backup guidance](https://mm.bradthomasbrown.com/wiki#backup)

## Status

Early beta, primarily used and tested in Orion on iPhone. Desktop browser support is experimental; this ZIP does not support Firefox. This GitHub release does not establish a new compatibility or security judgment.
